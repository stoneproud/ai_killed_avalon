# 八人阿瓦隆：密封信玩法

**目标：让好人完成三次任务，同时保护梅林的身份。**

适用条件：八人、五好三坏，梅林知道全部坏人，没有莫德雷德和湖中仙女。消息交换需要足够的通信轮次。下文描述消息必须满足的功能和参与者的行动，不指定某个软件或实现方式。

所有好人只按约定发言、选人、投票，不额外跳身份。每轮设结束时间，缺失消息按空信处理；名单统一编号，所有人按同一顺序选择。默认取座位号最小的人。

下面用一个假设座位讲解：**4号是梅林，坏人是3、5、8号，好人名单是1、2、4、6、7。**例子中的身份只用于说明，实际游戏中保持秘密。

## 1．先锁定答案，再发密封信

消息交换需要满足两个功能要求：

- **密封信：**公开发出加密消息，但只有指定收信人能读懂，并能确认来自哪个座位。
- **锁定答案：**先为一份固定名单公开一个凭证，再向有权核验的人提供名单和私密检查码。公开凭证不泄露名单；名单和检查码用于核验先前固定的答案，并防止事后换成另一份名单。

每个座位只公开一个凭证。先公开凭证，再发送名单。

| 身份 | 事先固定什么 | 发信内容 |
|---|---|---|
| 梅林 | 真实的五人好人名单 | 给好人发名单和检查码；给坏人发填充内容 |
| 其他好人 | “我没有名单” | 给所有人发填充内容 |
| 坏人 | 可以锁定一份假名单 | 发出的名单仍须通过后面的检查 |

在例子中，4号先锁定“1、2、4、6、7”，把公开凭证贴到公共频道。然后分别发信：

| 收信座位 | 4号发给他的内容 |
|---|---|
| 1、2、6、7 | 好人名单“1、2、4、6、7”，以及私密检查码 |
| 3、5、8 | 与普通好人相同格式的填充内容 |
| 4号自己 | 将自己的名单记作“收到”，参加后续确认 |

其他好人也给所有人发信。每个阶段，每人给另外七个座位各发一封信；该阶段要说的内容装在信里，没有内容就发填充；所有信补成同样长度。

**每封信只装收信人有权收到的内容；填充信不包含能打开本人凭证的检查码。**

## 2．收到名单后，按名单分别核对

收到一份名单，先做三项检查：

1. 是否恰好五人。
2. 是否包含发信人和收信人本人。
3. 是否能用检查码，通过发信人公开凭证的验证。

有一项不通过，就不采用这份名单。

接着，名单内五人通过密封信核对发信人。比如1号收到“1、2、4、6、7”，检查通过后，只给这五人发：

> 关于名单“1、2、4、6、7”：我检查通过，收到它的发信人是4号。

其他成员也按同样格式回复。若同一名单有多个来源，每人按约定座位顺序选一个来源，再互相核对。五人都确认通过、来源一致，才保留。

**这次核对只讲当前名单的来源。即使1号还收到了3号的另一份名单，也不能向3号提及这份名单来自4号。**

公开时，每个成员只回复：

> 我确认保留名单：1、2、4、6、7。

公开回复不带发信人、检查码或对应凭证。未确认的名单舍弃，保留的不同名单最多四份。

## 3．根据公开名单，安排备用队伍

“备用队伍”是每次任务的取人范围。准备最多三支，人数依次为四人、四人、五人。任务成功继续使用当前队伍，失败才换下一支。

### 只有一至三份名单

按统一编号给每份名单安排队伍：前两支各取名单中座位号最小的四人，第三支使用完整五人名单。不足三份时重复最后一份补齐。

例如：

| 公开名单 | 名单成员 | 对应备用队伍 |
|---|---|---|
| 甲 | 1、2、4、6、7 | 第一支：1、2、4、6 |
| 乙 | 1、2、3、5、6 | 第二支：1、2、3、5 |
| 丙 | 1、3、4、5、8 | 第三支：1、3、4、5、8 |

先使用第一支；它失败才换第二支，第二支失败才换第三支。

### 有四份，其中两份共享四个成员

选编号顺序最靠前的一对，第一支队伍使用它们的四个共同成员。

例如两份名单是“1、2、4、6、7”和“1、2、4、6、8”，第一支就用 **1、2、4、6**。

如果这支失败，同时删除这两份名单。后两支分别对应另外两份：一支取四人，一支保留完整五人。

### 有四份，任意两份都没有四个共同成员

按下一节处理。

## 4．四份名单没有四人交集时，具体怎么做

按座位顺序选一个出现在至少三份名单中的人，称为 A。

### A 出现在四份名单中

A 私下整理四位发信人的座位。在候选中，选出唯一一份“只包含这四位发信人中一人”的名单。

例如，A知道四位发信人是 **3、4、5、8**，就检查每份名单包含其中几人。“1、2、4、6、7”只包含4号，符合要求。

A只公布选出的名单，后续直接从这份名单取人，四位发信人继续保密。

### A 恰好出现在三份名单中

先把唯一不含 A 的名单叫作 X。取 X 中座位号最小的四人作为第一支队伍，成功继续用；失败后按以下步骤处理：

1. 删除 X。
2. 让 X 的五名成员公开报告 X 的发信人。不回答者各记为不同的“未回答”报告。
3. **若至少四人说同一个 F：**A把 F 和另外三份名单的发信人合在一起，按上一种情况选出名单。只公布名单，后续从中取人。
4. **若没有四人一致：**把报告同一发信人的人先归成小组，再将完整小组拼成一个两人组和一个三人组，不拆散小组。有多种拼法时，取座位顺序最靠前的两人组合。
5. 分别筛选“完全不含两人组成员”的名单，以及“完全不含三人组成员”的名单。把两种筛选结果合在一起，最多两份。
6. 用它们安排后两支备用队伍，一支取四人，一支保留完整五人。若只剩一份，后续直接从它取人。

下面是一组具体例子：

| 名单 | 成员 |
|---|---|
| 甲 | 1、2、4、6、7 |
| 乙 | 1、2、3、5、6 |
| 丙 | 1、3、4、5、8 |
| 丁 | 2、3、6、7、8 |

1号在甲、乙、丙中，所以 A 是1号，X 是丁。第一支队伍用 **2、3、6、7**。

这支失败后，删除丁，让丁中的五人报告来源。假设报告如下：

| 报告者 | 说名单丁来自谁 |
|---|---|
| 2、6、7 | 8号 |
| 3、8 | 5号 |

分成两人组 **3、8** 和三人组 **2、6、7**，再筛选：

- 完全不含3、8的，只剩甲。
- 完全不含2、6、7的，只剩丙。

因此后两支安排为：**甲的四人队伍“1、2、4、6”**，以及**丙的完整五人队伍“1、3、4、5、8”**。继续按成功不换、失败才换的规则执行。

**只有已经被任务失败排除的名单，才公开发信人。其他名单的来源保持私密。**

## 5．每轮到底派谁上任务

| 任务 | 选人方式 |
|---|---|
| 第一轮：三人 | 从当前备用队伍中，按座位顺序取三人 |
| 第二、三轮：四人 | 按座位顺序取四人 |
| 第四轮：五人，需两张失败票才失败 | 当前队伍有五人就全上；只有四人则补上队外座位号最小的一人 |
| 第五轮：五人 | 若任务阶段尚未结束，使用第三支完整五人队伍 |

例如当前备用队伍是 **1、2、4、6**：

- 三人任务派1、2、4。
- 四人任务派1、2、4、6。
- 第四轮需要五人，就补队外最小的3号，派1、2、3、4、6。
- 任一任务失败，才换下一支备用队伍。

即使3号投一张失败票，第四轮也仍算成功；这一轮需要两张失败票才失败。

若已经选出唯一名单，后续直接从该名单按座位顺序取所需人数，五人任务派名单全员。

**所有好人只批准上述规则选出的队伍，当队长时也只提出这支队伍。任务成功时不公开认定名单为真，继续照约定行动。**

条件性结果：如果上述消息交换、核验和行动条件成立，好人完成三次任务，且刺客仍只能在五名好人中等可能地猜测梅林，那么理想情况下好人最终胜率为80%。
